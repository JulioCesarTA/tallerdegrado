EXPORTAR REPORTE
----------------------------------------------------------------
1.  Autoridad    -> Metabase     : seleccionar reporte y formato (PDF / Excel / CSV)
2.  Metabase     -> Metabase     : exportarReporte(formato)
3.  Metabase     -> Repositorio  : SELECT vistas materializadas
4.  Repositorio  -> Metabase     : datos                       (return)
5.  Metabase     -> Metabase     : generar archivo (PDF / Excel / CSV)
6.  Metabase     -> Autoridad    : descarga del archivo        (return)
