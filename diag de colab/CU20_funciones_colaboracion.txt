FUNCIONES EN ORDEN - CU20: Buscar Vehiculo por Placa
(Diagrama de Colaboracion / Comunicacion)
Participantes: Operador - Vista (BuscarView) - Controlador (VehiclesController)
               - Service (VehiclesService) - Repositorio (prisma.vehiculo)
================================================================
(return) = marcar "Is Return" en EA (sin parentesis).
================================================================

BUSCAR VEHICULO POR PLACA
----------------------------------------------------------------
1.  Operador     -> Vista        : ingresar placa
2.  Vista        -> Controlador  : findAll(search)
3.  Controlador  -> Service      : findAll(search)
4.  Service      -> Repositorio  : findMany({ where: { placa: { contains: search } }, include })
5.  Repositorio  -> Service      : vehiculos[]                  (return)
6.  Service      -> Controlador  : vehiculos[]                  (return)
7.  Controlador  -> Vista        : resultados                   (return)
8.  Vista        -> Operador     : muestra vehiculo encontrado  (return)
