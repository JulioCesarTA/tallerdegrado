ACTUALIZACION DE VISTAS (ETL automatico cada 1 min)
----------------------------------------------------------------

2.  Service      -> Repositorio  : REFRESH MATERIALIZED VIEW (mv_accesos_diarios, mv_top_vehiculos, ...)
3.  Repositorio  -> Service      : ok                          (return)

VISUALIZAR DASHBOARD
----------------------------------------------------------------
1.  Autoridad    -> Metabase     : abrir dashboard de BI
2.  Metabase     -> Repositorio  : SELECT vistas materializadas (mv_accesos_diarios, mv_permanencia, ...)
3.  Repositorio  -> Metabase     : datos agregados             (return)
4.  Metabase     -> Autoridad    : muestra graficos e indicadores   (return)
