================================================================================
BASE DE DATOS - SISTEMA DE CONTROL VEHICULAR UAGRM (versión final)
================================================================================

TABLAS Y ATRIBUTOS
================================================================================

1. Permission
   - id   : Int    (PK, autoincrement)
   - name : String (UNIQUE)

------------------------------------------------------------------------

2. Role
   - id   : Int    (PK, autoincrement)
   - name : String (UNIQUE)

------------------------------------------------------------------------

3. RolePermission  [tabla intermedia]
   - roleId       : Int (FK -> Role, CASCADE)
   - permissionId : Int (FK -> Permission, CASCADE)
   PK compuesta: (roleId, permissionId)

------------------------------------------------------------------------

4. User
   - id       : Int    (PK, autoincrement)
   - name     : String
   - email    : String (UNIQUE)
   - password : String
   - roleId   : Int    (FK -> Role)

------------------------------------------------------------------------

5. CameraType
   - id   : Int    (PK, autoincrement)
   - name : String (UNIQUE)
   Valores: entrada, salida

------------------------------------------------------------------------

6. CameraStatus
   - id   : Int    (PK, autoincrement)
   - name : String (UNIQUE)
   Valores: activa, inactiva, falla, mantenimiento

------------------------------------------------------------------------

7. Camera
   - id             : Int     (PK, autoincrement)
   - name           : String
   - location       : String
   - cameraTypeId   : Int     (FK -> CameraType)
   - cameraStatusId : Int     (FK -> CameraStatus)
   - streamLink     : String?

------------------------------------------------------------------------

8. TipoVehiculo
   - id   : Int    (PK, autoincrement)
   - name : String (UNIQUE)
   Valores: moto, auto

------------------------------------------------------------------------

9. Vehicle
   - id             : Int     (PK, autoincrement)
   - plate          : String  (UNIQUE, INDEX)
   - brand          : String?
   - model          : String?
   - tipoVehiculoId : Int?    (FK -> TipoVehiculo)
   - color          : String?

------------------------------------------------------------------------

10. AccessPoint
    - id            : Int    (PK, autoincrement)
    - name          : String
    - location      : String
    - entryCameraId : Int    (FK -> Camera, UNIQUE)
    - exitCameraId  : Int    (FK -> Camera, UNIQUE)
    - userId        : Int    (FK -> User)

------------------------------------------------------------------------

11. AccessLog
    - id              : Int       (PK, autoincrement)
    - vehicleId       : Int       (FK -> Vehicle, CASCADE, INDEX)
    - accessPointId   : Int?      (FK -> AccessPoint, SET NULL)
    - ingresoCameraId : Int?      (FK -> Camera, SET NULL)
    - salidaCameraId  : Int?      (FK -> Camera, SET NULL)
    - ingresoAt       : DateTime  (default: now, INDEX)
    - egresoAt        : DateTime? (null = vehiculo aun adentro)
    - evidenceUrl     : String?

------------------------------------------------------------------------

12. Sanction
    - id                   : Int       (PK, autoincrement)
    - vehicleId            : Int       (FK -> Vehicle, CASCADE)
    - sanctionDefinitionId : Int       (FK -> SanctionDefinition)
    - startsAt             : DateTime  (default: now)
    - endsAt               : DateTime?

------------------------------------------------------------------------

13. SanctionDefinition
    - id           : Int    (PK, autoincrement)
    - name         : String
    - reason       : String
    - durationDays : Int

------------------------------------------------------------------------

14. AlertType
    - id   : Int    (PK, autoincrement)
    - name : String (UNIQUE)
    Valores: camera_disconnected, camera_error, detection_failure,
             sanctioned_vehicle_attempt, network_failure, system_interruption

------------------------------------------------------------------------

15. Alert
    - id          : Int      (PK, autoincrement)
    - alertTypeId : Int      (FK -> AlertType)
    - cameraId    : Int?     (FK -> Camera, SET NULL)
    - createdAt   : DateTime (default: now)

================================================================================
RELACIONES
================================================================================

  Permission       <--  RolePermission        -->  Role
  Role             <--  User
  User             <--  AccessPoint            (userId)
  CameraType       <--  Camera                 (cameraTypeId)
  CameraStatus     <--  Camera                 (cameraStatusId)
  Camera           <--  AccessPoint            (entryCameraId)
  Camera           <--  AccessPoint            (exitCameraId)
  Camera           <--  AccessLog              (ingresoCameraId)
  Camera           <--  AccessLog              (salidaCameraId)
  Camera           <--  Alert                  (cameraId)
  AccessPoint      <--  AccessLog              (accessPointId)
  TipoVehiculo     <--  Vehicle                (tipoVehiculoId)
  Vehicle          <--  AccessLog              (vehicleId)
  Vehicle          <--  Sanction               (vehicleId)
  SanctionDefinition <-- Sanction              (sanctionDefinitionId)
  AlertType        <--  Alert                  (alertTypeId)

================================================================================
RESUMEN
================================================================================

  Total tablas : 15
  Sin enums    : CameraType, CameraStatus y AlertType son tablas
                 normalizadas con id y name
  Todos los IDs: Int (autoincrement), sin cuid
  AccessLog    : un registro por visita (ingresoAt + egresoAt)
                 en lugar de un evento por tipo

================================================================================
