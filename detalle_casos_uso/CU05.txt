Caso de Uso
CU05. Gestionar Cámaras
Propósito
Administrar las cámaras del sistema de control vehicular.
Descripción
El administrador puede registrar, consultar, editar y eliminar cámaras, indicando su ubicación, tipo y estado.
Actores
Administrador
Actor Iniciador
Administrador
Precondición
Haber iniciado sesión como Administrador.
Proceso
1. El administrador accede al módulo de Cámaras.
2. El sistema lista las cámaras registradas.
3. Para registrar una nueva, ingresa nombre, ubicación, tipo de cámara y estado.
4. El administrador puede editar o eliminar una cámara existente.
5. El sistema guarda los cambios.
Postcondición
Cámara registrada, actualizada o eliminada correctamente.
Excepciones
Si la cámara no existe, el sistema muestra "Cámara no encontrada".
